# Money Kiwi

Money Kiwi is a full-stack personal budgeting application for tracking accounts, transactions, recurring activity, transfers, savings, investments, and debt.

## Live Demo

https://moneykiwi.com

A temporary demo session is available from the login page with pre-populated sample data.

## Features

- Account and balance tracking
- Income, expense, and transfer transactions
- Recurring transactions
- Category management
- Cash-flow and investment dashboards
- Email verification and password reset
- Temporary seeded demo sessions
- Responsive interface

## Tech Stack

- React
- React Router
- TanStack Query
- React Hook Form
- Zod
- Express
- PostgreSQL
- Prisma
- Nodemailer / Resend

## Project Goals

I built Money Kiwi as a practical budgeting tool and as a larger full-stack project to deepen my experience with API design, authentication, relational data, validation, and financial data visualization.
